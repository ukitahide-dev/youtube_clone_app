YouTube風のWebアプリ（React + Django）

## URL
https://my-youtube-frontend-bdqg.onrender.com
※ Render無料プランのため、初回アクセス時に起動まで少し時間がかかる場合があります。

## 使用技術
- Frontend: React / Vite
- Backend: Django / Django REST Framework
- Auth: JWT (SimpleJWT)
- DB: SQLite（開発環境）、PostgreSQL(本番環境)
- Graph: Recharts

## 主な機能
- ユーザー認証（登録・ログイン・JWT認証）
- 動画の投稿 / 再生 / 編集 / 削除 / 検索
- いいね
- コメント
- プレイリスト作成・管理
- チャンネル登録機能
- 自身のチャンネルにおける月別再生回数・視聴時間・登録者数の推移

## 工夫した点
- フロントとバックエンドを完全に分離し、REST APIを通じてデータをやり取りする構成にしました。
- 認証状態をフロント側で管理し、ログイン状態に応じて表示を切り替えました。
- 動画ファイルに関して、開発環境ではmp4ファイルを扱っていましたが、本番環境では容量やパフォーマンスを考慮し、
  YouTubeのembed URLを保存する方式に変更しました。

## 苦労した点
- JWT認証の仕組み理解に時間がかかりましたが、リクエストの流れを図に書いて整理しました。
- DjangoとReactのデータ形式の違いに悩みましたが、APIレスポンスを統一することで解決しました。
- 視聴用プレイリストと投稿用プレイリストの設計に苦労しました。当初は1つのプレイリストテーブルで管理していましたが、
  役割の異なるデータを1つの構造で扱うことでロジックが複雑になりました。
  そのため途中で設計を見直し、視聴用と投稿用でテーブルを分けることでデータ構造を整理しました。

## 開発背景
フロントエンドとバックエンドを分けたWebアプリ開発の流れを理解するため、
認証・API設計・フロント連携を含むYouTube風アプリを制作しました。
